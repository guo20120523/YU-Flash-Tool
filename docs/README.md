## 当前能力与风险边界

源码已有真实 raw 写入：仅限独立、可写、未挂载/映射的已知 boot 类或系统文件系统物理分区与完整等长镜像。非 A/B 可以符合条件，A/B 仅非当前槽位；动态/Virtual A/B 拒绝。Bootloader 解锁、电量至少 50%、温度 0–42°C 和设置要求均须满足。

导入不立即刷写，但进一步确认会真实覆盖。写前强制完整备份，首字节前比较原目标全量哈希，固定同 FD 写入、同步与读回；**AVB、回滚、机型兼容性仍未证明**，须显式勾选接受风险并准确输入分区名。没有安全取消、自动重试/回滚/重启/切槽或启动能力保证。

持久写入意图成功后也保留，成功许可仅在原进程内；同一次启动的新进程即使面对旧成功记录，也会保守禁止设备操作、导入与清理。设置和日志导出仍允许。有效记录仅在不同 boot ID 时不再阻挡资格检查，不应为此盲目重启；损坏记录须人工支持。

## 如何理解验证用语

- **源码已实现／静态核对**：路径存在或已审阅，不等于编译、运行或设备验证成功。
- **测试已编写／正在运行／待结果**：只有断言源码或尚未完成的执行，不可写成“通过”。
- **编译通过**：生成了产物，不等于 UI 已启动、仪器测试执行或真实设备读写验收。
- **单元模拟通过**：对应报告中的普通文件、假设备或内存端点断言通过，不能替代块设备测试。
- **历史证据**：只对应当时源码和运行；旧版硬件写入关闭、旧测试/Lint 数字不描述当前 raw 写入状态。
- **用户反馈**：机型、复现和日志不足时不提升为兼容认证。
- **设备验收**：应包含明确机型、系统/Root 环境、步骤与证据。当前没有新链路硬件写入测试或完整适配清单。

阅读文档、看到 Release、检查通过或哈希相符，都不构成设备可启动或可恢复的保证。

## 文档与产物版本

项目首页和通用指南不维护逐版本更新列表或固定结果数量。变化、修复、限制和构建结果统一写在 Releases；发行说明源文档是发布输入，不是另一个累积更新日志。

仓库主分支文档可能比所下载 APK 更新。以该 Release 的完整提交、说明、源码和校验资料为准；文字更新不会使历史 APK 获得新能力，也不会使未运行测试变成通过。
