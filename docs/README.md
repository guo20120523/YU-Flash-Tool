## 当前能力与风险边界

主页通过“一键获取分区表”主动请求 Root 并发现分区，实际加载文字为“正在读取分区表”。发现范围有限，RPMB 在内容探测前跳过，不承诺整盘或所有块设备支持。

**写入已改为确认后的直接 `dd`，不是旧版受限 raw 事务。** 从 `content://` URI 流复制到私有普通文件，不解析格式、计算写入哈希或按分区容量拒绝；sparse、压缩包和未知内容均作为原始字节，不展开、不解压。单个危险确认框展示目标名、设备路径、文件字节数及警告与免责声明，不要求准确输入名称或兼容性预检。

确认后串行执行固定 `/system/bin/toybox dd`，仅在其返回 0 后单独执行 Toybox `sync`。没有强制备份、大小/类型/槽位/AVB/Bootloader/挂载/动态分区/电量/温度/可写性策略，没有旧 `RootWriter` / `VerifiedCopy` 或读回验证。非零 `dd` 终止，无自动重试或回滚；同步错误也不是成功。

应用保留引用与基本路径约束、当前任务重复提交防护，但**只检测自己的运行任务，不锁定其他进程/工具**。旧不确定标记不再阻止直接流程；旧进程的 Root 后代 `dd` 仍可能存活。前台服务、超时与取消不保证其退出，可能继续写入或留下部分损坏。挂载中或动态存储也可能被损坏。

手动“读取”与备份仍使用旧保守读取策略，保存长度、哈希与元数据；它可能被拒绝，且不会自动执行。备份校验不是恢复或在线一致性保证。

## 如何理解验证用语

- **源码已实现／静态核对**：路径存在或已审阅，不等于编译、运行或设备验证成功。
- **测试已编写／待 CI**：没有对应执行报告前，不可写成“通过”。
- **编译通过**：不等于 UI 已启动、仪器测试已执行或真机读写验收。
- **单元模拟通过**：只覆盖该运行中的假执行器、普通文件或内存端点，不等于 Root/块设备验证。
- **历史证据**：旧版测试和 Lint 只描述当时源码；旧检查、强制备份、固定 FD 和读回不再是活动写入路线。
- **命令成功**：直接写入只表示 `dd` 和 `sync` 返回 0，不包含读回、兼容性、可启动性或恢复验证。
- **正式发行**：指版本、签名与产物的发布方式，不是设备安全认证。本次签名与构建是否完成，应查看真实 CI 证据。
- **设备验收**：应有机型、系统/Root 环境、步骤与日志。当前没有直接写入真机验收或完整适配清单。

本轮本地没有已安装的 SDK/JDK，不声称完成新构建或测试；Android 仪器测试历史上仅编译、未执行。旧测试数量不能作为新路线通过数。

## 文档与产物版本

项目首页和通用指南不维护逐版本更新列表或固定结果数量。变化、修复、限制和实际构建结果统一写在 Releases；发行说明源文档是发布输入，不是累积更新日志。

主分支文档可能领先于 APK。以所选 Release 的完整提交、说明、源码和校验资料为准；文档更新不会让旧 APK 获得新能力，也不会使未运行测试变成通过。
