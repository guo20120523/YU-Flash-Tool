## 如何理解验证用语

- **源码已实现**：代码路径存在，不等于在你的设备上验证过。
- **编译通过**：工具链生成了产物，不等于 UI 已启动或真实读写经过测试。
- **单元模拟通过**：普通文件与假设备上的断言通过，不能替代块设备测试。
- **用户反馈**：由使用者报告的体验；机型、复现与完整日志不足时不提升为兼容认证。
- **设备验收**：应包含明确机型、系统/Root 环境、步骤和证据，目前没有完整适配清单。

当前硬件写入始终关闭。阅读文档或看到 Release 不构成可以刷写设备的授权或保证。
