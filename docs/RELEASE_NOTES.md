## 应用能力与边界

YU-Flash-Tool 是 Kotlin / Jetpack Compose / Material 3 原生 Android 分区工具，提供主动 Root 授权、限定 by-name 分区发现、符合策略的读取备份、本地镜像导入检查和持久化任务记录。

- **主页**：查看设备与分区、搜索排序筛选、读取备份、镜像检查和目标详情。
- **任务**：查看阶段与结果，导出脱敏记录；不自动续写或恢复。
- **设置**：主题、动态取色、列表密度、容量单位、备份目录、通知及诊断。
- **关于**：应用信息、作者昱yu、QQ 3895958954、源码与 GPL v3。

**真实硬件写入保持关闭。** 镜像检查不是刷写、AVB 验证或设备兼容认证；不提供自动恢复、回滚或绕过校验功能。

## 下载与安装

1. 下载 `YU-Flash-Tool-debug.apk`；`YU-Flash-Tool-androidTest.apk` 是仪器测试包，不是主应用。
2. 按附件校验表核对摘要，保留与 APK 同提交的源码、构建身份和报告。
3. 在受控测试设备上安装。此包最低 Android API 26、目标 API 35；不构成全机型兼容承诺。
4. 首次浏览界面不必授权 Root，发现分区和读取时再主动授权。读取前核对目标、路径、空间和风险。

这是 Debug 安全预览包，不是生产签名稳定版。GitHub 临时 runner 的 Debug 签名可能与旧包不同；若无法覆盖安装，不要贸然卸载，先导出需要保留的记录。卸载会删除应用私有任务记录与暂存；持久更新签名方案尚待建立。
