# 0.1.1-safety-preview

## 这个版本可以做什么

YU-Flash-Tool 是 Kotlin / Jetpack Compose / Material 3 原生 Android 分区工具，提供主动 Root 授权、限定 by-name 分区发现、符合策略的读取备份、本地镜像导入检查和持久化任务记录。**真实硬件写入关闭**，不是通用刷机器或救砖方案。

- **主页**：查看设备与分区、搜索排序筛选、五列读取与镜像检查入口、目标详情。
- **任务**：查看阶段与结果，导出脱敏记录；不自动续写或恢复。
- **设置**：主题、动态取色、列表密度、容量单位、备份目录、通知及诊断。
- **关于**：版本、作者昱yu、QQ 3895958954、源码与 GPL v3。

## 下载与开始使用

1. 下载 `YU-Flash-Tool-debug.apk`；`YU-Flash-Tool-androidTest.apk` 只是仪器测试包，不是主应用。
2. 按附件校验表核对摘要，保留匹配的源码、构建身份和报告。
3. 在受控测试设备上安装；首次只浏览界面不需要授权 Root，发现分区和读取时再主动授权。
4. 小屏上可上下滑动主页、左右滑动表格；读取前必须核对目标、路径、空间和风险，镜像检查不会刷入设备。

完整操作见 [用户指南](https://github.com/guo20120523/YU-Flash-Tool/blob/main/docs/USER_GUIDE.md)，构建证据以本发布对应提交与附件为准。反馈请在 [Issues](https://github.com/guo20120523/YU-Flash-Tool/issues) 提供版本、构建标签、机型、复现步骤与脱敏日志，不上传备份、镜像、Token 或设备指纹。

## 安装及安全边界

- 这是 Debug 安全预览版，不是稳定版或生产签名包。Android 最低 API 26，目标 API 35；不构成全机型兼容承诺。
- 真实块设备写入保持关闭；本次只调整主页滚动及发布流程，没有开放刷写、自动恢复、回滚或 AVB 绕过。
- RPMB 被普通探测触发 I/O 错误的问题尚未修复，不能把本次更新当成该问题的修复。
- 用户反馈此前在 Android 手表上做过基础/只读测试，但具体机型与完整步骤未收集；不是维护者独立设备验收。本次小屏变更尚需手表验证，圆屏边缘、旋钮操作及所有对话框适配未验收。
- CI 会编译 UI 测试 APK，但不会执行模拟器/真机测试。测试和 Lint 数字由本次实际 XML 自动填写；警告不隐瞒。
- GitHub 临时 runner 的 Debug 签名可能与旧包不同；若安装提示签名不一致，不要贸然卸载，先导出需要保留的私有任务记录。卸载会删除应用私有数据。后续稳定更新需要独立的持久签名方案。
- APK 同包源码、许可和校验值应一起保存。第三方传递依赖许可审计尚未全部完成。
