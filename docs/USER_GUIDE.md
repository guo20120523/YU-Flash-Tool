# 用户指南

[返回首页](<../README.md>) · [构建说明](<BUILD.md>) · [安全设计](<SAFETY_DESIGN.md>)

> 本指南介绍通用操作流程；下载、版本变化、验证结果及已知问题请查看所选版本的 [Releases 页面](https://github.com/guo20120523/YU-Flash-Tool/releases)。**真实刷写与恢复未开放**，不要把镜像检查或备份成功理解为已经具备恢复能力。

## 1. 启动与 Root

应用有“主页、任务、设置、关于”四个页面。首次打开不会自动申请 Root；阅读用途后，在主页点击“了解用途并申请 Root”。Root 管理器的授权提示由设备自身环境决定。未授权时仍可查看设置和历史任务。

检测检查 `su` 是否取得 uid 0，并用应用自有普通临时文件验证系统 Toybox 行为。缺少 `su`、拒绝授权、超时、工具不可用或无法读取设备信息都会阻止继续。不能把 Root 已取得理解为 Bootloader 已解锁，也不能将工具自检称为完全无写入：**自检会写临时普通文件，但不写块设备**。

如出现超时，不要连续点击重试。超时后的 `su` 后代进程状态不能保证，须先核实 Root 管理器及任务状态。应用不提供任意 Shell 命令入口。

## 2. 浏览分区

主页提供名称搜索、按名称/大小/类型排序、槽位与风险筛选以及“仅可读取”筛选。可上下滚动主页、左右滚动五列表格；点击分区名称或大小查看真实块路径、设备号、原始字节数、槽位、风险、挂载/映射状态和重复别名。

- 列表只从限定的常见 by-name 路径发现目标，不是全设备所有分区的承诺。
- 类型来自文件内容签名，不凭 `.img` 扩展名判定。
- “仅可读取”表示通过当前本地策略筛选；不代表执行时 Root、空间或目标身份检查一定通过。
- `userdata`、`metadata`、`cache` 等 `Risk.DATA`、挂载中/挂载未知及映射目标被读取策略拒绝。没有匹配项时先检查筛选条件与诊断，不要绕过检查。

## 3. 读取并备份

1. 在“设置”中明确选择备份父目录 `/sdcard/download` 或 `/sdcard/Download`。默认使用前者，路径不存在/不可写时不会自动换成后者，也不支持任意目录。
2. 点击分区的“读取”，核对确认框中的目标、容量、保存目录及可用空间。
3. 理解在线读取和隐私风险后点击“理解风险并备份”。Android 13+ 可能请求通知权限；运行期间使用前台服务通知，系统仍可能终止进程。
4. 等待任务记录结论。备份读取阶段没有可靠百分比，不要将不定进度条误认为精确完成比例。

目标目录按下列规则生成（这是设备端输出示意，不是工程中的文件）：

```text
<明确选择的下载目录>/YU-Flash-Tool/<设备标识>/<时间戳>-<任务ID>/
    <分区名>.img
    metadata.json
```

备份需要整分区大小加至少 **64 MiB** 余量。实际读取先写 `.img.partial`，完成长度、目标身份及文件 SHA-256 复核后提交镜像和元数据；元数据含分区、设备号、构建指纹、字节数和哈希等。独立任务目录用于避免覆盖已有备份。

**完成条件不是“出现 .img 文件”。** 请查看任务是否记录验证成功，保留配套元数据；失败、进程退出、掉电或最终提交失败时，残留文件可能不完整，回退为 `.partial` 仅为最佳努力。不要自行改后缀冒充验证完成，也不要把哈希一致理解为必定能恢复。

下载目录不是应用私有空间。分区备份可能含敏感信息，避免共享、云同步及无关应用访问。当前没有恢复入口，不要尝试在此预览版内恢复备份。

## 4. “写入检查”只是导入检查

1. 点击目标行的“写入检查”，通过系统文档选择器选择已经保存到本地的镜像。
2. 仅接受 `content://` URI 且文件描述符是普通文件；云端流、管道、流设备不被接受。请先将云端文件保存为本地普通文件再选择。
3. 应用将内容复制到私有暂存目录，按实际读取字节数控制上限和剩余空间，并计算 SHA-256。原始文档不会被重命名或改写。
4. 空文件、内容未知、截断 boot 镜像、Android sparse、压缩包/压缩镜像/OTA 包会被拒绝；扩展名改为 `.img` 不能改变结果。
5. 检查弹窗显示目标、槽位、容量、类型和哈希。选择“关闭（不写入）”结束；**没有继续真实刷写的确认入口**。

识别到 EXT4/F2FS/EROFS/AVB 等签名不等于验证了完整文件系统或设备兼容性；当前写入策略只为未来经审核的 boot 类完整等长 raw 镜像设计。当前设备注册表为空、OTA 快照与 AVB 状态未知，而且硬件写入方法直接抛错。

导入过程中异常提供器可能在打开文件时忽略取消；应用尝试取消信号和关闭文件描述符，但**不能承诺阻塞提供器立即停止**。当前没有“任意时刻安全取消”保证。

## 5. 任务、后台与中断

“任务”页列出阶段、时间、任务 ID、槽位、字节数及可用退出码。导入的 `SUCCESS` 只表示导入检查成功；备份的 `SUCCESS` 只表示备份校验完成；不能统称为“刷写成功”。

任务使用前台服务、进程内互斥及唤醒锁。源码设定 5 小时任务预算；这些措施不是持续运行保证，未经过 Android 生命周期和真机验证。切换页面不会主动发起新任务；重复提交会被拒绝而非排队。

进程再次启动后，未结束的记录会标记为 `INTERRUPTED`；应用不会自动续写、重试、回滚或重启。直接 `su` 进程被强制结束，也不能保证全部后代进程结束。中断后应先检查目标和存储状态，再决定是否发起独立任务。

## 6. 设置与清理

- 外观：跟随系统/浅色/深色、Android 12+ 动态取色、紧凑列表、二进制容量单位。
- 备份：只支持两种明确大小写的下载目录。
- 写入策略设置：最低电量 50%–100%、是否要求充电；温度范围 0–42°C。这些是应用的保守策略，不是 Android 官方统一安全标准，修改设置也不会开放当前写入。
- 强制备份与 SHA-256 校验没有关闭开关；显示高风险对象或更多诊断不会绕过策略。
- “只读任务完成通知”不关闭运行中的前台服务通知；通知可见性还受系统权限影响。
- “清理所有私有暂存镜像（保留备份）”仅在没有运行任务时可用，会清除暂存镜像，不删除下载目录备份。当前不应宣称成功后自动清理已实现。

## 7. 导出与隐私

在“任务”页选择“导出脱敏记录”，阅读说明后选择保存位置。导出仅含时间、任务 ID、分区名、槽位、阶段、字节数和退出码，不含设备指纹、文件路径、镜像内容及错误原文。但分区名与时间仍可能暴露使用情况；“脱敏”不是完全匿名。

应用清单未声明网络权限；所读源码没有广告/分析 SDK 配置。系统文档提供器或下载目录同步软件是另一个边界，不能由此保证它们不联网。卸载会清除应用私有记录与暂存，下载目录备份通常仍在，需要用户自行保护和管理。
