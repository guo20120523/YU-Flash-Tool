# 用户指南

[返回首页](<../README.md>) · [构建说明](<BUILD.md>) · [安全设计](<SAFETY_DESIGN.md>)

> 本指南介绍通用流程；版本变化、验证结果及已知问题请查看所选版本的 [Releases 页面](https://github.com/guo20120523/YU-Flash-Tool/releases)。**直接 `dd` 会真实覆盖分区，没有镜像或设备兼容性检查、强制备份或读回验证。** 当前没有真机写入验收；错误输入可能造成数据丢失、无法启动或变砖。本应用没有自动恢复入口，正式发行不等于安全认证。

## 1. 启动、Root 与获取分区表

应用有“主页、任务、设置、关于”四页。首次打开不会自动申请 Root。在主页点击 **“一键获取分区表”**，主动触发授权及发现；根据设备 Root 管理器提示处理授权，实际加载文字为 **“正在读取分区表”**。未授权时仍可浏览设置和历史任务。

Root 检测核对 `su` 的 uid 0 和所需工具，普通临时文件自检不会向块设备写入，但不是零文件写入。缺少 `su`、拒绝授权、超时、工具不可用或必要设备信息无法读取可能阻止发现。Root 不代表 Bootloader 已解锁，也不证明任何文件适合目标。

超时后不要连续点击。直接 `su` 进程结束不证明其后代已停；应用不提供任意 Shell 输入，也不为外部 Root 工具加锁。

## 2. 浏览分区

主页提供搜索、排序及筛选，可上下滚动主页、横向滚动五列表格。点击分区名称或大小查看设备路径、设备号、原始字节数、槽位、别名、内容类型和挂载/映射等信息。

- 只从限定的常见 by-name 路径发现目标，不保证列出所有分区，不承诺整盘目标支持。
- RPMB 是特殊协议设备：按别名和真实设备名过滤，在普通内容探测前跳过，不提供 RPMB 内容读写、格式化或密钥操作。
- 列表类型来自发现时的内容信息，不是对所选输入文件的解析。名称、类型或容量看起来相同不代表兼容。
- “仅可读取”等筛选反映手动读取策略，不是直接写入许可。隐藏、风险分类和详情展示不构成写入阻止条件。
- 直接写入不检查挂载、动态/映射、当前槽位等风险；发现信息也不等于写入瞬间的设备状态。

## 3. 手动读取并备份：独立且仍受限制

1. 在设置中明确选择备份父目录 `/sdcard/download` 或 `/sdcard/Download`。不会把两种大小写静默视为同一位置，不支持任意目录。
2. 点击目标“读取”，核对目标、容量、保存目录和可用空间。
3. 阅读在线读取与隐私风险后确认。Android 13+ 可能请求通知权限；前台服务不保证系统永不终止进程。
4. 等待备份结果。读取阶段没有可靠百分比，不定进度条不是精确完成比例。

设备端输出示意（不是仓库文件）：

```text
<明确选择的下载目录>/YU-Flash-Tool/<设备标识>/<时间戳>-<任务ID>/
    <分区名>.img
    metadata.json
```

这条路线保留保守 `SafetyPolicy` 和旧读取互锁：DATA、挂载中/挂载未知、映射对象或旧不确定标记等可能导致拒绝，还需复核身份、目录和空间。备份需要整分区大小及至少 **64 MiB** 余量；先写临时文件，检查长度、SHA-256 和身份后提交镜像及元数据，任务目录不复用已有备份。

**手动备份不是直接写入的前置步骤，也不会由写入自动调用。** 读取被拒绝不代表写入会被拒绝，更不能据此判断写入可靠。需要备份或外部救援的，应自行安排并验证，而不是期待应用代办。

文件出现不是完成证明，须检查任务结果并保留配套元数据。单独备份的哈希对象是文件，没有独立原设备再次全量一致性验证，不保证在线文件系统一致性或可恢复性。下载目录可能被其他应用或同步软件访问，备份可能含敏感数据。

## 4. 选择文件 → 危险确认 → 直接写入

### 4.1 复制文件（此步不写目标设备）

1. 点击目标行的“写入”，通过系统文档选择器选择文件，返回 `content://` URI。
2. 应用将可读取的内容流复制成私有目录里的普通文件，统计实际字节数。源文档不改写，提供器展示名不作为命令或私有路径。
3. **不解析镜像、不算写入校验哈希、不按格式、类型或目标容量拒绝。** sparse、ZIP/其他压缩包和未知文件都可作为输入，不会展开或解压。空文件或小于/大于分区的文件也不因镜像大小策略被拒绝。
4. 等待复制完成后查看危险确认。URI 无法打开、授权撤销、私有空间不足、读写错误或中断仍可能使复制失败；这是 I/O 失败，不是兼容性判断。

输入可以来自能提供读取流的文档提供器，并非要求源文件描述符必须是本地普通文件。提供器可能阻塞或忽略取消，不能承诺及时退出；其网络访问行为不受应用离线权限约束。

### 4.2 一个危险确认框

确认框展示**目标分区名、发现的设备路径、实际文件字节数**以及警告和免责声明。核对后勾选已阅读并接受警告，点击“确认并直接写入”才提交；关闭确认框不写目标。

不再要求准确输入目标名，不再有“检查写入条件”、强制备份或兼容性放行步骤。必须理解：

- 文件将按原始字节直接覆盖目标；sparse/压缩包不会转换，可能破坏分区格式。
- 不核对大小、类型、槽位、AVB、回滚、Bootloader、挂载、动态/Virtual A/B、电量、温度或目标可写性。
- 可能覆盖当前使用中的存储、关键固件或不合适的目标；Root/系统也可能在部分写入后才报错。
- 不会自动生成备份，没有读回、自动重试、回滚、切槽或重启；确认只表示接受风险，不证明兼容。
- 仅在自己有权操作并能承担损坏后果的设备上操作，外部救援能力需独立准备。

### 4.3 提交后的真实顺序

```text
明确确认 → 应用内串行任务 → 固定 dd 写入
  ├─ dd 非零 / 异常：失败或中断，不重试、不回滚
  └─ dd 返回 0 → 单独 sync
       ├─ sync 非零 / 异常：失败或中断，不报成功
       └─ sync 返回 0 → 记录命令完成（无读回验证）
```

固定命令如下，参数来自私有副本和发现目标，不接受任意 Shell 输入：

```text
/system/bin/toybox dd if=<引用后的私有文件路径> of=<引用后的已发现 /dev/block 路径> bs=1048576
/system/bin/toybox sync
```

`dd` 读到文件末尾，不按分区大小补零、清尾、截断输入或展开格式。短文件可能留下原目标尾部；空文件不提供有效刷写；过长文件可能部分写入后才因容量/I/O 错误退出。日志中的文件字节数不是独立验证出的介质写入量。

活动写入不经过旧 `FlashTransaction`、`RootWriter`、`VerifiedCopy`，没有固定同一目标 FD 的哈希对照、写入和读回链路。

## 5. 任务、后台与中断

“任务”页的成功含义必须按操作区分：

| 操作 | 成功仅表示 |
| --- | --- |
| 文件复制 | 私有副本复制完成，未验证格式、兼容性或目标内容 |
| 手动备份 | 相应备份长度/哈希等检查完成，不保证一致性或恢复 |
| 直接写入 | `dd` 和随后 `sync` 返回 0，**未读回验证、未验证可启动性或恢复能力** |

任务使用前台服务、应用内互斥和超时处理；重复提交拒绝而不排队。**应用只知道自己当前运行的任务，不锁定其他进程或其他工具。** 页面空闲不证明整个设备没有写操作。

**没有安全取消保证。** 超时、取消、服务结束、系统杀进程或掉电可能使应用中断；结束直接 `su` 进程不能保证后代 `dd` 已退出。它可能继续改写，也可能留下部分损坏。旧不确定写入标记不再阻止直接流程，重开应用并不会据此阻断；旧进程遗留的 `dd` 不能由当前忙碌状态可靠识别。

未结束任务会被标记为中断，不自动续写、重试或恢复。失败、无终态或没有日志都不证明目标未被写过。此时应停止重复操作，保留日志和已有备份，由有能力的人员核实进程与设备状态；不要盲目重启、清数据或卸载来“修复”。

## 6. 设置与清理

- 外观：跟随系统/浅色/深色、动态取色、列表密度与容量单位。
- 手动备份：两种明确大小写的下载目录，不静默回退。
- 直接写入：没有强制备份/哈希、最低电量、充电、温度或目标风险策略。旧参数或旧核心策略存在不代表活动写入仍受保护。
- 通知：完成通知设置不取消运行期间的前台服务要求，可见性仍受系统权限影响。
- 清理：无当前运行任务时可手动清理私有暂存，保留下载目录备份。当前应用空闲不代表旧 Root 子进程已经停止；状态不明时不要清理。

## 7. 导出、安装与隐私

任务页可导出脱敏记录，包含时间、任务 ID、分区名、槽位、阶段、字节数和退出码，不包含指纹、路径、镜像内容或错误原文，仍非完全匿名。应用不声明 INTERNET 权限，无广告/分析 SDK 配置；外部文档提供器、同步软件和 Root 进程不在这一范围内。

发布签名和安装提醒见对应 [Release](https://github.com/guo20120523/YU-Flash-Tool/releases) 及[签名说明](<SIGNING.md>)。旧 Debug 与稳定发布签名通常不同，不能直接覆盖安装；需要卸载重装时，先保存必要记录和备份，并确认设备操作已经结束。卸载会删除私有记录与暂存，通常不删除下载目录备份，但不保证终止遗留 `dd`，更不会撤销已写入内容。
