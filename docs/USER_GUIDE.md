# 用户指南

[返回首页](<../README.md>) · [构建说明](<BUILD.md>) · [安全设计](<SAFETY_DESIGN.md>)

> 本指南介绍通用流程；版本变化、验证结果及已知问题查看所选版本的 [Releases 页面](https://github.com/guo20120523/YU-Flash-Tool/releases)。**写入前必须自动完整备份并复核，写入后必须读回校验，但这不是镜像/设备兼容性或恢复保证。** 真实 `dd` 仍可造成数据丢失、无法启动或变砖；当前没有本次真机写入验收，也没有安全取消或自动恢复入口。

## 1. 启动、Root 与获取分区表

应用有“主页、任务、设置、关于”四页。首次打开不会自动申请 Root。在主页点击 **“一键获取分区表”**，主动触发授权及发现；根据设备 Root 管理器提示处理授权，加载文字为 **“正在读取分区表”**。未授权时仍可浏览设置和历史任务。

Root 检测核对 `su` 的 uid 0 和所需工具，普通临时文件自检不向块设备写入，但不是零文件写入。缺少 `su`、拒绝授权、超时、工具不可用或必要设备信息无法读取可能阻止发现。Root 不代表 Bootloader 解锁，也不证明文件适合目标。

超时后不要连续点击。直接 `su` 进程结束不证明其后代已停；应用不提供任意 Shell 输入，也不为外部 Root 工具加锁。

## 2. 浏览分区

主页提供搜索、排序及筛选，可上下滚动主页、横向滚动五列表格。点击分区名称或大小查看路径、设备号、原始字节数、槽位、别名、内容类型和挂载/映射等信息。

- 只从限定的常见 by-name 路径发现目标，不保证列出所有分区，不承诺整盘目标支持。
- RPMB 是特殊协议设备：按别名和真实设备名在普通内容探测前跳过，不提供 RPMB 内容读写、格式化或密钥操作。
- 列表类型来自发现时的内容信息，不是对所选输入的解析。名称、类型或容量相同不代表兼容。
- 读取资格不是写入兼容性证明；但**不满足备份策略就不能通过本次写入的自动备份前置步骤**。
- 发现信息与备份检查不保证写入瞬间状态不变，不提供贯穿整个任务的固定目标 FD 或全系统设备锁。

## 3. 备份目录与完整备份

### 3.1 先准备目录和空间

在设置中明确选择备份父目录 **`/sdcard/download` 或 `/sdcard/Download`**。不会把两种大小写静默视为同一位置，不支持任意目录，也不会在一处失败后自动换另一处。

需要的可用空间是**整个目标分区容量加至少 64 MiB 余量**，而不只是源文件大小。短镜像仍需完整分区备份；此外私有存储须有空间暂存源文件。空间检查不是预留，其他应用仍可能耗尽空间。

### 3.2 手动读取与写入前自动备份

可点击目标“读取”，核对目标、容量、目录和空间，阅读风险后确认；这是独立的手动备份。**每次写入任务确认后还会自动生成本次完整备份，不能跳过，不能用已有手动备份替代。** Android 13+ 可能请求通知权限；前台服务不保证进程不会被终止。

设备端输出示意（不是仓库文件）：

```text
<明确选择的下载目录>/YU-Flash-Tool/<设备标识>/<时间戳>-<任务ID>/
    <分区名>.img
    metadata.json
```

手动和自动备份复用现有保守 `SafetyPolicy.backup` 与备份实现：

1. 容量、设备路径和 `major:minor` 身份必须有效；拒绝 DATA、挂载中或挂载状态未知、映射或映射状态未知目标。未知/关键风险分类本身不一定拒绝读取。
2. 复核目标身份、所选目录与空间；读取路径保留的互锁等拒绝也不能绕过。
3. 建立不复用已有备份的唯一任务目录，先写 `.img.partial`，同步并检查完整分区长度与 SHA-256，再复核身份和文件摘要。
4. 提交镜像及元数据；两者不是跨文件原子事务。孤立镜像、`.partial` 或文件出现本身不代表完整成功。
5. 写入任务还必须执行 `verifyBackup`，再次核对长度、文件摘要及元数据。任何失败都不得进入本次 `dd`。

保留镜像与配套元数据。备份文件哈希不是独立原设备再次全量一致性证明；在线块读取不是一致性快照，备份存在也不保证可恢复。下载目录可能被其他应用或同步软件访问，备份可能含敏感数据。

## 4. 选择文件 → 确认 → 备份 → 写入与读回

### 4.1 复制文件（此步不写目标设备）

1. 点击目标行的“写入”，通过系统文档选择器选择文件，返回 `content://` URI。
2. 应用将读取流复制成私有目录里的普通文件，统计实际字节数。源文档不改写，提供器展示名不作为命令或私有路径。
3. **不解析镜像，不按格式或文件/分区相对大小判断兼容性。** sparse、ZIP/其他压缩包和未知文件均原样复制，不展开、不解压、不转换；接受输入不是正确刷包支持。
4. URI 无法打开、授权撤销、空间不足、读写错误或中断仍可导致暂存失败。复制统计不是写前摘要；自动备份及复核后会重新测量实际源长度和 SHA-256。

输入可来自能够提供读取流的文档提供器，不要求原源描述符是本地普通文件。提供器可能阻塞或忽略取消，其网络访问不受应用离线权限约束。

### 4.2 一个危险确认框

确认框展示**目标名、设备路径、实际文件字节数**以及警告和免责声明。阅读并明确确认才提交；关闭确认框不提交写入任务。不要求准确输入目标名，也没有镜像格式/机型兼容性放行步骤。

确认前必须理解：

- 确认后先自动备份，**不能选择“无备份继续”**；备份策略拒绝、目录不可用或空间不足会阻止写入。
- 文件按原始字节覆盖；sparse/压缩包不会转换，读回一致也不能证明格式正确。
- 未恢复 AVB、回滚索引、槽位、Bootloader、电量、温度等兼容性准入，不能把备份策略当作完整设备安全检查。
- 短输入仅覆盖并验证前缀，未触及尾部不验证；过长输入可能部分改写后才失败。空文件也不是有效刷写。
- 无自动重试、回滚、切槽或重启；用户确认不证明适配。外部救援能力需独立准备。

### 4.3 提交后的真实顺序

```text
明确确认 → 应用内串行任务
  → 完整自动备份（现有保守读取策略、所选目录、64 MiB 余量）
  → verifyBackup（长度 / SHA-256 / 提交元数据）
  → 测量写前源实际长度与 SHA-256
  → 固定 dd
       ├─ 非零 / 异常：失败或中断，不重试、不回滚
       └─ 返回 0 → 独立 sync
                      ├─ 非零 / 异常：失败或中断
                      └─ 返回 0 → 只读助手读回 [0, 写前源长度)
                                      → 长度 / SHA-256 与写前源一致
                                      → 再测源长度 / SHA-256，检测修改
                                      → 全部通过才 SUCCESS
```

备份、备份复核或写前源测量失败时，不启动本次 `dd`；实际源长度与已确认的导入字节数不符、摘要无效同样拒绝。这是源文件一致性检查，不是与分区等长的要求。写入后的读回不足、I/O 错误、长度/哈希不一致、源修改或复核错误均不得报告成功。

固定命令如下，参数来自私有副本和发现目标，不接受任意 Shell：

```text
/system/bin/toybox dd if=<引用后的私有文件路径> of=<引用后的已发现 /dev/block 路径> bs=1048576
/system/bin/toybox sync
```

`dd` 读到文件末尾，不按分区大小补零、清尾、截断输入或展开格式。只读助手由已安装 APK 经 `app_process` 启动，流式读取精确字节范围并计算摘要；不生成大型额外临时镜像，也不用会掩盖读取错误的 Shell 管道。

**读回只覆盖写前源长度**。即便完整备份覆盖整个分区，短镜像写后仍没有验证未写尾部。活动写入不经过旧 `FlashTransaction`、`RootWriter`、`VerifiedCopy` 的固定独占 FD 事务；备份、`dd` 和读回按各自步骤访问，状态可能在期间变化。

## 5. 任务、后台与中断

| 操作 | 成功仅表示 |
| --- | --- |
| 文件复制 | 私有副本复制完成，未验证格式或兼容性 |
| 手动备份 | 相应备份长度/摘要等检查完成，不保证在线一致性或恢复 |
| 写入 | 本次完整备份及复核完成，dd/sync 成功，精确范围读回长度/摘要与写前源一致，源复核一致；不验证尾部、启动、恢复或掉电持久性 |

任务使用前台服务、应用内互斥和超时；重复提交拒绝而不排队。**只知道自身当前任务，不锁定其他进程或 Root 工具。** 备份路径继承的互锁可能阻止任务，但不是固定目标 FD 或当前 `dd` 的跨进程生命周期保证。

**没有安全取消保证。** 超时、取消、服务停止、系统杀进程或掉电可能中断应用；结束直接 `su` 进程不保证后代 `dd` 已退出。它可能继续改写，也可能留下部分损坏。页面空闲、旧标记、成功/失败日志都不是全系统无写入证明。

未结束任务标为中断，不自动续写、重试或恢复。失败、无终态或没有日志不证明未写入。应停止重复操作，保留日志和备份，由有能力的人员核实进程与设备状态；不要盲目重启、清数据或卸载来“修复”。

## 6. 设置与清理

- 外观：跟随系统/浅色/深色、动态取色、列表密度与容量单位。
- 备份目录：手动和自动备份使用明确选择的下载目录，不静默回退。
- 写入：自动备份、`verifyBackup`、源摘要和读回不可跳过；未恢复最低电量、充电、温度或完整兼容性开关。
- 通知：完成通知设置不取消运行期间前台服务要求，可见性仍受系统权限影响。
- 清理：无当前运行任务时可手动清理私有暂存，保留下载目录备份。空闲不代表旧 Root 子进程已停止；状态不明时不要清理。

## 7. 导出、安装与隐私

任务页支持脱敏导出，仍含时间、任务 ID、分区名、槽位、阶段、字节数及可用退出码，分享前自行核对。应用不声明 INTERNET 权限，无广告/分析 SDK 配置；文档提供器、同步软件和其他 Root 进程不在此范围内。

发布签名和安装提醒见对应 [Release](https://github.com/guo20120523/YU-Flash-Tool/releases) 及[签名说明](<SIGNING.md>)。正常发布更新应沿用原证书，不更换密钥；是否匹配以真实证书核验为准。旧 Debug 与发布签名可能不同，不能直接覆盖安装。确需卸载重装时，先保存记录和备份，并确认设备操作结束。卸载会删除私有记录及暂存，通常不删除下载目录备份，但不保证终止遗留 `dd`，也不撤销已写内容。
